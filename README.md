

# Chatty 💬

Chatty is a simple and lightweight chat application where users can enter their name, send messages, and view messages in a shared chat section.

## Features
- Enter your name and message.
- Send messages using the Send button.
- View messages along with the sender's name.
- Simple and clean user interface.
- Hosted using GitHub Pages.
